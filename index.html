Быстрые действия

С чего начать работу
ⓘ

Важно о текущей версии. Сейчас это интерактивный прототип: основные действия работают в браузере, XML можно проверить на корректность структуры и признаки заполнения. ИИ-анализ документов, актуальная XSD-валидация по всем схемам Росреестра и получение данных из государственных систем пока не подключены.

Предварительный контроль

Проверка техплана

Прикрепите электронный техплан и исходные документы. Помощник выполнит базовую локальную проверку XML и сформирует перечень пунктов для ручной сверки.

01 Файлы для проверки

⇧
Перетащите файлы сюда

или выберите на компьютере
XML для локальной проверки; XML, PDF, DOCX, TXT, JSON для анализа ИИ · файлы ИИ будут переданы API провайдера

Пока нет прикреплённых файлов. Добавьте XML для локальной проверки или XML/PDF/DOCX/TXT/JSON для анализа ИИ.

02 Контекст проверки

Заметка попадёт в итоговый отчёт. Это не заменяет обязательные разделы техплана.

Что проверяется сейчас

Доступны базовые проверки, не зависящие от серверного ИИ.

✓Корректность разбора XML (если приложен XML)
✓Поиск вероятного кадастрового номера в XML и форме
✓Наличие контекста: вид объекта и основание
·Проверка обязательных полей по актуальной XSD-схеме Росреестра
·Сверка графики, координат, площадей и исходных документов

Перед началом

Для полноценной проверки обычно нужен именно XML-пакет техплана, а также документы, на основании которых он подготовлен.

🔒

Локально. Локальная проверка не отправляет файлы. Кнопка анализа ИИ передаёт выбранные поддерживаемые файлы на сервер и провайдеру ИИ; не загружайте документы без разрешения и согласия на обработку.

ИИ-помощник
Здравствуйте! Я помощник кадастрового инженера. Могу помочь составить список проверок для технического плана, объяснить возможные замечания, подготовить вопросы заказчику или разобрать сведения из карточки объекта. Начните с конкретного вопроса. Для анализа содержимого файлов откройте «Проверка техплана» и нажмите «Анализ ИИ». Мои ответы требуют проверки по актуальным нормативным документам.
Не отправляйте лишние персональные данные.

Чем поможет ассистент

✓Подготовить предварительный чек-лист для типа объекта и основания работ
✓Объяснить замечание понятным языком и предложить следующий шаг
✓Составить список недостающих документов и вопросов заказчику
✓Помочь систематизировать сведения и подготовить внутренний отчёт

Подключение ИИ

Для настоящих ответов нужен серверный маршрут /api/chat и секретный ключ провайдера, сохранённый в настройках хостинга. Не вставляйте API-ключ в HTML или публичный GitHub.
